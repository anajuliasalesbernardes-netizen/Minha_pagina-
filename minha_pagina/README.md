# 🌐 Minha Página

Projeto simples de página pessoal/landing page criada com HTML, CSS e JavaScript.

## ✨ Sobre o projeto

Este projeto consiste em uma página inicial com layout moderno, visual limpo e elementos interativos básicos. Ele foi desenvolvido para servir como base para apresentação pessoal, portfólio ou perfil online.

## 📁 Estrutura do projeto

- `index.html` — estrutura da página
- `estilo.css` — estilos e layout visual
- `script.js` — interações e comportamento do site
- `README.md` — documentação do projeto

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ▶️ Como executar

1. Abra o arquivo `index.html` no seu navegador.
2. Se preferir, você pode usar um servidor local simples para visualizar melhor o projeto.

Exemplo com Python:

```bash
python -m http.server 8000
```

Depois acesse:

```bash
http://localhost:8000
```

Demonstrar habilidades de criação de interfaces web com foco em simplicidade, estética e responsividade.
